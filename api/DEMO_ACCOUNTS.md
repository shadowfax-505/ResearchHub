# Local Demo Accounts

The demo network is fictional local development data. Run `npm run seed:demo-network` from `api` after the Oracle migrations.

All demo researcher accounts use the password `ResearchHubDemo!2026` and usernames `demo_researcher_01` through `demo_researcher_20`.

The moderator account is `researchhub_demo_admin` with the same local-only password. Demo emails use the reserved `researchhub.local` domain and do not send mail.
